# Java Dev Bootstrap 设计说明

## 目标

构建一个面向公众发布的跨平台 Java 开发环境初始化工具。用户在新的 Windows 或 macOS 电脑上运行命令后，可以查看推荐的软件清单、检查环境状态，并在明确确认后安装 Java 开发所需的软件与组件。

## 第一版范围

- 支持 Windows 10/11 与 macOS。
- 提供 `list`、`plan`、`install`、`doctor` 四个命令。
- 通过 YAML 清单描述软件包、平台、安装器类型和说明。
- Windows 优先调用 `winget`，macOS 优先调用 Homebrew。
- 默认使用 Eclipse Temurin JDK 21、Git、Maven、Gradle、IntelliJ IDEA Community、Visual Studio Code、Docker Desktop。
- 安装前展示计划并要求显式确认；支持 `--yes` 用于自动化场景。
- 每条外部命令写入日志，失败时返回可读的中文错误。
- 重复执行时先检查已安装状态，尽量跳过已满足的软件。

## 非目标

第一版不包含图形界面、后台自动更新、离线镜像、企业设备管理、自动修改 shell 配置文件和账号登录。

## 架构

CLI 层负责参数、输出和确认；应用层负责加载清单、按当前平台筛选并生成安装计划；端口层负责环境探测和执行外部命令；配置层负责 YAML 解析与校验。各层通过小接口隔离，便于测试和未来增加 Linux、GUI 或其他包管理器。

## 安全与可重复性

- 只执行清单中明确声明的命令参数，不拼接用户输入到 shell 字符串。
- 默认预览计划，安装必须确认。
- 记录命令、退出码和输出摘要，但不记录环境变量中的潜在密钥。
- 清单版本化，包管理器 ID 使用精确匹配。
- 未安装包管理器时停止并提示官方安装地址或下一步操作。

## 未来演进

核心包编译为单文件后，通过 GitHub Actions 和 GoReleaser 发布；GUI 使用 Wails 复用同一应用层与端口层；插件机制以新增清单和执行器接口为主，不让插件直接获得任意 shell 权限。
